# Code of Conduct

This project serves Muslims and Chinese-language readers across different regions, schools, and technical backgrounds. Contributors are expected to keep discussions useful, respectful, and evidence-based.

## Expected behavior

- Treat religious topics with adab, humility, and care.
- Discuss translation differences as scholarly questions, not personal attacks.
- Provide reproducible technical details for bugs and credible sources for data corrections.
- Welcome contributors who are new to GitHub, open source, Arabic, Chinese, or Islamic studies.

## Unacceptable behavior

- Harassment, insults, sectarian provocation, or discriminatory language.
- Deliberate misinformation about Quranic text, translation sources, or project licensing.
- Publishing private security details before maintainers have had a reasonable chance to respond.
- Spam, advertising, or unrelated political arguments.

## Enforcement

Maintainers may edit, hide, or close issues and pull requests that violate these expectations. Serious or repeated violations may result in blocked participation. For sensitive concerns, contact `bropeace@protonmail.com`.
