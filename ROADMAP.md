# Roadmap

This roadmap is intentionally practical: it focuses on reliability, data trust, and maintenance capacity for a free public-interest Quran search tool.

## Current priorities

- Establish reproducible validation for five complete Chinese translations.
- Improve issue and pull request triage so community reports can be handled consistently.
- Document data provenance and correction requirements.
- Keep the static site easy to mirror by mosques, schools, and community groups.

## 2026 H2

- Add stronger generated HTML escaping and regression tests for search highlighting.
- Add a lightweight browser smoke test for PC and mobile entry points.
- Publish release notes for each public deployment.
- Add more explicit accessibility checks for keyboard navigation and mobile layout.

## 2027

- Build an optional semantic-search layer that can run with low-cost embeddings while keeping the offline keyword search available.
- Improve multilingual metadata for Chinese-speaking Muslims outside mainland China.
- Expand documentation for community mirrors and low-bandwidth deployments.
- Add structured provenance notes for each translation source and known edition.

## Long-term

- Preserve Chinese Islamic translation heritage as searchable digital humanities data.
- Provide a reliable free reference tool for students, imams, teachers, and researchers.
- Keep the project independent of advertising and paywalls.
