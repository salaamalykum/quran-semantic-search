# Support

## User support

For ordinary usage questions, open a GitHub issue or email `bropeace@protonmail.com`.

Useful details:

- PC or mobile URL used,
- browser and operating system,
- search keyword,
- screenshot or screen recording when helpful.

## Data quality reports

For Quran translation corrections, include:

- surah number and ayah number,
- translator name,
- current repository text,
- proposed correction,
- source evidence.

Reports without source evidence may still be useful, but they will usually be triaged as needing verification.

## Security reports

Use the private process in `SECURITY.md`.
