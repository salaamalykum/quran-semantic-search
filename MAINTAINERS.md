## Maintainer responsibilities

- Review pull requests for correctness, accessibility, performance, and provenance risk.
- Triage issues into bug, data correction, documentation, security, or enhancement work.
- Keep `pc/`, `mobile/`, generated SSR pages, and datasets consistent.
- Run validation before releases and deployment changes.
- Protect the project mission: free, non-profit, ad-free access for Chinese-language Quran study.

## Maintainer decision principles

- Quran text and translation data changes require source evidence.
- User-facing features should work on low-bandwidth networks and older mobile devices when practical.
- Automation should make maintenance safer and more reproducible.
- The project should avoid unnecessary tracking, advertising, or commercial dependencies.
